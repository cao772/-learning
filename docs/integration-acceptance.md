## 浏览器端到端烟测

合成浏览器数据脚本：
- `scripts/integration-smoke-server.py`：隔离 SQLite 临时库、测试密码，只监听本地 `127.0.0.1:8765`。
- `tests/integration-browser.cjs`：Playwright + 真正 Chromium 桌面/手机，覆盖匿名课程与筛选、匿名 API 隔离、站主登录、兴趣发现、手工链接、私人研究计划保存，以及手机浏览。
- `.github/workflows/browser-smoke.yml`：安装 Chromium 自动运行并上传**合成样本截图**到 GitHub Actions artifact。**严禁上传用户真实数据、云端截图或凭据。**

运行（允许本地 Docker 外的测试系统、GitHub CI）：

```sh
python -m pip install -r requirements.txt
npm install --no-save playwright@1.56.1
npx playwright install chromium
node tests/integration-browser.cjs
```

若 CI 不通过，不能声称浏览器真实验收通过。若通过，也只代表**GitHub CI 隔离合成环境**通过，尚须上线后实际浏览器验收真实域名、证书、权限、数据和同步情况。

## 生产上线闸口

1. 核实 ICP 审核通过及准入；备案申请不等于通过。
2. 在授权主机执行只读审计：`bash deploy/host-security-audit.sh`；核对腾讯云防火墙+UFW、SSH 登录策略、Docker 监听地址。
3. 制作生产 SQLite 一致性快照并下载加密副本，至少隔离恢复一次；记录原云端镜像的不可变版本和回滚流程。
4. 审核 PR #3、#4、#5、#6、#7 的集成结果；在独立环境用复刻生产配置部署和完整回归，符合要求后才审批合并/生产发布。
5. 备案与安全准入完成后，在明确授权下上线 Caddy TLS、DNS 与 HTTPS；验证匿名公开阅读、站主私人数据隔离、备份/告警、实际 Mac→云端同步。
6. 未经授权禁止修改或关闭当前 `127.0.0.1:18788` SSH 隧道云端稳定版，禁止关闭服务器 SSH 以致远程锁死。

## 证据边界

- GitHub CI **不等于生产上线**。
- 脚本审计 **不等于主机已加固**。
- 数据源目录 **不等于微信/小红书全部自动抓取成功**。
- GitHub 星数、许可证、论文全文、实际复现情况未知时仍应标明未知。
