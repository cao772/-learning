# 循序 learning｜个性化发现工作台 V1

当前生产试运行口径：腾讯云服务器上已有 4 条精选、候选和 30+16 课程可匿名浏览；`yanhaoo.com` 仍在办理 ICP 备案。**本分支只提供代码和测试，不代表已经云端部署。**

## 真实需求与兴趣体系

围绕用户四类职业角色与开放探索兴趣建立 8 个可调权重：Agent/MCP/工程工具、开源项目和实用产品、算法/模型评测、系统架构、产品/商业、论文前沿、自然/生物/数学、技术管理协作。默认是从已有项目经验整理的**起始规则**，不是通过模型自动推断的真实偏好评分。

来源：[Notion《AI信息源》](https://app.notion.com/p/64e7bbed1352825e848b817eb493009b)。当前展示的网站/博主包含 AIHOT、BestBlogs、歸藏的 AIGC Weekly、Github、小红书、数字生命卡兹克、机器之心、新智元、量子位、Super黄、云中江树、海外独角兽、通往 AGI 之路、集智俱乐部、宝玉、Lil'Log、红杉资本、a16z 和 NYU 课程。**目录仅代表关注，不代表获得抓取授权、更新成功或已阅读原文。**

## 新增功能

- 站主导航新增 **兴趣发现**；公开首页仍只展示原有精选、候选及 46 节课程。私人视图通过登录会话访问 `GET /api/discover`。
- **透明排序**：对现有候选和精选按标题/摘要/主题/链接关键词、兴趣权重、最近 14 天、编辑核验状态和显式阅读反馈打分，附“为什么推荐”。只针对元数据匹配，关键词提示的项目关联需要验证，不提供假的 GitHub 星数、论文实测、产品成熟度或模型推理。
- **可编辑兴趣**：站主按 0～5 权重调整八类兴趣，使用已有 `/api/state/profile:interests` revision 冲突保护和数据库持久化；可调成“最近偏爱产品、暂时不读理论”，不强制锁死初始人设。
- **随手收集私密链接**：站主从小红书、GitHub、公众号复制原文链接，`POST /api/capture` 带 CSRF，存入 `personal` 私人命名空间。规范 URL、去掉追踪参数、识别 Github 项目大小写去重。无自动访问外链，因此不会导致 SSRF 或假采集。私密条目不会进入公共 `items`、匿名 HTML 或同步给其他人。
- **来源地图**：展示信息源类型、手动入口和接入状态，供后续按合法可用的 RSS/API/订阅来源增加适配器。保留原有收件箱和精选审核链路。

## 数据与安全边界

- `HUB_PUBLIC=1` 不代表发现工作台可匿名查看；`/api/discover`、`/api/capture` 走原有鉴权/CSRF；手工链接不会进入公共精选。
- 自动收集程序不调用大模型。对于微信或小红书受限内容，优先用户主动分享链接和许可的导出，不绕过验证、不批量抓取私人内容。
- `/api/ingest` 现有契约仍沿用；候选不自动升级精选。编辑核验与“已实测”两者不同；未知发布日期不推断为发布当天。
- `personal` 私人存储包含收藏、反馈、偏好、人工发现；已有 SQLite 备份与 /api/export 保持兼容，敏感数据不提交公开 GitHub。
