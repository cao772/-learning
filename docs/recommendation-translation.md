# 循序 learning｜推荐质量与双语阅读（V5）

## 目标及现状

承接 [PR #9](https://github.com/cao772/-learning/pull/9) 的九个独立主分类、人工校正和搜索。用户新增要求：**内容翻译也要做**。本轮提供明确选择的中文双语阅读，不强制开启付费模型，不改变原本不调用模型 API 的采集程序。

### A. 面向个人的推荐排序

- 基于原有标题、时间、显式关键词、核验状态与用户权重，再结合**明确收藏**、反馈（如值得深读、证据不好）和主动建立的研究计划做有限、有界排序。
- 对个人历史反馈量很少的情况**不推断偏好**；必须有明确动作才产生加权。同一类别/来源的偏好最多影响有限分数，绝不能将候选升级精选。
- 首页前 12 项对来源和内容类别做**柔性分散**，减少某一个来源或 Agent 技术文章霸屏；当没有替代信息时自动回退，不删除、不漏掉已收集内容。
- 每条保留已有「为什么推荐」理由，若顺序受到历史反馈或分散策略影响，增加可解释提示。
- 站主 `GET /api/discover` 返回 `recommendation` 说明与使用的明确行为线索数；不是模型信心分或事实质量分。
- **不**分析未授权的浏览器历史、微信群、小红书账户、电子邮件，不训练模型或调用外部服务。

### B. 英语资讯、论文摘要与 GitHub 条目双语阅读

- 在站主的精选/候选与「兴趣发现」及私人链接增加「中英双语」；并排显示**已收录标题/摘要原文**，独立显示中文译文，手机端上下排列。
- 可**人工填写/修订**中文译文，始终可用且无需任何接口。保存到 SQLite `personal` 的 `translation:<item_id>`（仅站主），保留原文来源链接。
- 可选**按需自动翻译**。当前支持通过服务器私有配置接入 DeepL 翻译 API；没有提供商密钥时按钮禁用、提示手工填写，**不冒充机器翻译已经成功**。
- 自动翻译只有**本人主动点击**才触发；单次只上传当前已有的标题（最多 500 字符）和摘要（最多 3000 字符），不爬取原站全文、不发送私人笔记、不会批量翻译整个采集库。
- 自动请求经服务器转发到固定 HTTPS DeepL URL，密钥只保留在服务器私有环境变量，不写进浏览器、GitHub 或日志。每天最多 **10 次**外部请求（按 UTC 时间窗统计），相同摘要已缓存的不重复扣次数；费用/字符配额由 DeepL 套餐决定。
- 缓存用原标题与摘要 SHA-256 指纹；来源摘要更新后不展示过期译文，提示翻译需要重新校验。
- 每条译文标注「站主人工录入」或「DeepL 机器译文，未经人工校核」。技术术语/论文结论可能误译，应以原始资料为准；人工修订不会修改编辑核验状态。
- 当前没有开通翻译 API、没有对用户资料发起实际 DeepL 请求；外部翻译能力只有配置并授权后才可生产使用。

### 生产配置

在腾讯云服务器受控的私有 `.env` 添加（不得提交 GitHub）：

```
HUB_TRANSLATE_DEEPL_KEY=<secret stored privately>
HUB_TRANSLATE_DEEPL_PLAN=free
```

如果账号是 DeepL Pro，则套餐值改为 `pro`。`deploy/compose.production.yaml` 会把可选字段仅注入 Flask 后端容器。缺少 Key 时站主照样可手动填写中文译文。若未来替换腾讯云 TMT、离线 ArgosTranslate 或其他经过许可的翻译服务，可保留同一接口与缓存逻辑，不应绕过审批自动连接。

### 验证与边界

- Python 测试检验推荐多样性/完整性/反馈边界、翻译授权/CSRF/缓存、人工修订/revision、数据更新失效、每日上限及翻译请求不读取原文网站。
- Playwright Chromium 用**合成数据**测试站主双语页面、保存后回显、自动提供商未配置时禁用、其他私人功能及手机匿名访问。
- 原始文档和 46 课不变；无需数据库迁移。公开访客不能读取私有翻译，匿名站点仍是旧设计的精选/候选+课程。
- **尚未部署腾讯云真实主机**，不能把 CI 当成自动翻译在真实服务可用、原始论文翻译精准或域名公开已上线；ICP备案是否通过仍待独立核实。
