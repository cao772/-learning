# 循序 learning｜内容分类 V4：人工校正与类别内搜索

本次在 [分类拆分 PR #8](https://github.com/cao772/-learning/pull/8) 基础上补齐真实使用闭环，而非增加更多预设栏目。Agent、论文、代码项目、产品、教程等仍为互斥主分类，技术兴趣标签独立保留。

## 交互

1. 私人「兴趣发现 → 为我发现」支持即时搜索**当前已加载**的卡片内容，按现有类别筛选；只做浏览器端过滤，不访问第三方站点或调用大模型。
2. 每条精选/候选卡片增加「纠正分类」，可以从 9 类中选择，附加可选的 200 字私人说明。私人手工保存的 GitHub/公众号/小红书链接也可纠正。
3. 站主选择「恢复自动分类」后，重新使用链接/标题的保守规则。每次变更都通过现有 revision 冲突锁保证不会无提示覆盖另一设备。
4. 显示分类原因与明确的「站主手动归类，非内容事实核验」。这不等于 AI 判断正确、不等于原文核验、更不会把候选升级为精选。
5. 分类筛选统计随服务端当前排名视图刷新；不影响 46 节离线课程、已有收藏、笔记、同步程序与公开访客阅读。

## 数据与接口

- 仍使用 SQLite `personal` 私人记录，不变更数据库表结构或 `items` 原始数据。
- key: `category:<feed-id>` 或 `category:capture:<hash>`。value: `{"category":"paper","note":"手动核实为论文"}`；`category="auto"` 重置自动判断。
- 原有 `PUT /api/state/<path:key>`，必须有站主登录、CSRF 和 revision；拒绝虚构 ID、未定义类别、任意附带字段和超长备注。
- `GET /api/discover` 每条排名记录与私人手工链接新增 `category_override`、`category_note`、`category_revision`，并应用更正后的唯一主分类进行计数及同类别跨源关联。
- 对外匿名首页及 `/api/items` 没有这些私人字段；不公开私人原因备注，也不变更来源事实。

## 测试

- `tests/test_category_feedback.py` 覆盖鉴权、CSRF、有效/无效类别、手工更正、恢复自动、revision 冲突、已有数据和重新导入后的更正保留、私人手工链接、更正不泄漏公开页面。
- Playwright `tests/integration-browser.cjs` 在隔离合成数据环境中验证类别内搜索、手动纠正、保存重开、恢复自动与独立类别切换。
- 现有 Python/Node、安全加固、46 课构建及 Docker CI 保持运行。

## 边界

这只是候选内容的**个人浏览分类**，不是自动内容质量打分。不会自动修改原始采集器与已编辑核验结果。当前腾讯云上仍是旧版，尚未部署此 Draft PR；ICP备案审批通过状态尚未独立核实。
