# V6 人工审核前端

基于后端 PR #14 `f3ccc38a`，仅新增独立前端、前端测试与说明，不改 Python、算法、评测门槛、现有网页或生产配置。

入口：`frontend/v6-review/index.html`，可直接在浏览器打开。也可从仓库运行：

```sh
python3 -m http.server 8876 --bind 127.0.0.1 --directory frontend/v6-review
```

打开 http://127.0.0.1:8876 。仅服务前端目录，不对外暴露原始报告/数据库。此为手动预览，不是常驻部署任务。

一次选择同一输出目录的 report.json、pair-labels.csv、relevance-labels.csv。填写审核者后，使用「事件对照」或「推荐相关性」分栏判断，可搜索与过滤未标注项；模型线索默认折叠，避免先把候选当作真值。原文以安全新标签打开，所有标题/摘要按纯文本呈现。

判断暂存在页面内存；分别点击「导出事件标注」「导出推荐标注」并确认两个文件均下载。未导出离页有浏览器提示，不使用浏览器持久化，也不上传文件。原始列顺序、未知列和既有标注保留；报告ID不一致、重复ID、缺列、非法标注值拒绝加载。导出的CSV应交回后端评测，不能把浏览器按钮当作归并批准或发布。

**不填写真实质量结论**：前端仅记录操作者判断，不能证明人类身份；自动测试的点击只发生在明确标记 synthetic-ui-test 的合成材料。实际593条材料标注仍为空。后端人工审核/来源核验仍由对应负责人负责。
