## 已修复的实际问题

- 中文目录使 Compose 推导项目名为空：显式设置 `name: xunxu-hub`。
- macOS LaunchAgent 无权限读取文稿目录：撤下失败任务，改用已获文件访问的 Docker 挂载运行现有采集器，未扩大系统隐私权限。
- 过期候选若已收藏，直接删除会留下孤立个人记录：现在清除订阅摘要，仅保留原文链接与个人笔记。
- 云端课程 JSON 键顺序不同会误报冲突：改为稳定排序比较，并保留实际冲突双方副本。
- 历史精选离开滚动 feed 后不应凭新快照补造采集时间：适配器保留原文/核验日期，缺采集时间为 null。

## 同步故障回归补验

- 保存请求失败期间继续编辑：保留最新本机内容，5 秒后重试；旧请求不能覆盖新队列。
- 409 多设备冲突、401/403 会话失效：暂停自动写入，提示刷新处理，防止盲目覆盖。
- 采集超时：进入 300 秒失败退避；采集日期标记损坏可恢复，成功标记采用原子替换。
- 15 项 Python 测试和 4 项真实桥接脚本的 Node 故障回归通过。重建本地 Docker 后，服务健康、4 条真实精选读取、重启持久化和备份恢复再次通过。
